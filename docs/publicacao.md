# Critérios de publicação desta vitrine

Antes de adicionar qualquer arquivo, conferir:

1. O material foi criado para esta vitrine ou sua divulgação foi autorizada.
2. Nomes, fotos, documentos, credenciais e valores operacionais reais não aparecem.
3. A imagem ou o vídeo usam dados fictícios e foram revisados quadro a quadro.
4. Nenhum código da aplicação, do Adianti ou configuração de servidor foi copiado por engano.
5. Histórico e metadados do arquivo não revelam dados que não devam ser públicos.

Os arquivos publicados são intencionalmente limitados. Um `.gitignore` ajuda a evitar inclusões acidentais, mas não substitui a revisão do conteúdo antes de cada envio.
